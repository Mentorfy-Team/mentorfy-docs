**Notificaciones es donde envías avisos a tus alumnos, por el canal correcto: correo, WhatsApp, SMS o llamada.**

Aquí aprendes a:

- escribir un aviso con el nombre de cada alumno y elegir quién lo recibe;
- programar el envío para la hora correcta;
- revisar en el historial si el aviso llegó.
