Stuck on something? The fastest way is to ask for help from inside the platform, with the **Need help?** button.

## Step by step

<Passos>
  <Passo titulo={<>Click <strong>Need help?</strong>, at the bottom of the side menu.</>}>
    The **Como podemos ajudar?** (How can we help?) window opens.
  </Passo>
  <Passo titulo={<>Choose the type of support.</>}>
    **Suporte Técnico** (Technical Support) for questions, errors, and problems. **Informações sobre Planos** (Plan Information) for subscription, payment, and upgrades. Both options open a WhatsApp conversation.
  </Passo>
  <Passo titulo={<>Send your message with the items in the list below.</>} />
</Passos>

:::tip First time on the platform?
In the same window, the **Platform tour** shows the main features in 2 minutes.
:::

## What to send to get help fast

1. **Your account email** on Mentorfy.
2. **A screenshot** of the screen where the problem shows up, with the error message, if there is one.
3. **The step by step** of what you did before the problem showed up.
4. **Which student, mentorship, or group** it happened with, if that applies.

## Reference

| Channel | When to use it |
| --- | --- |
| **Need help?** (inside the platform) | The main way: questions, errors, and questions about plans. |
| **Technical Support WhatsApp** | [Open a conversation](https://wa.me/551130429643). The same as the **Suporte Técnico** button. |
| **Email** | [suporte@mentorfy.io](mailto:suporte@mentorfy.io), for matters that need attachments or more details. |
| **Support center** | [mentorfy.io/suporte](https://mentorfy.io/suporte) (Portuguese) · [mentorfy.io/support](https://mentorfy.io/support) (English). |

**Support hours:** 12 p.m. to 10 p.m., Brasília time.
