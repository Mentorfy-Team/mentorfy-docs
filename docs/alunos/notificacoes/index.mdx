**Notificações é onde você manda avisos para os seus alunos, no canal certo: e-mail, WhatsApp, SMS ou ligação.**

Aqui você aprende a:

- escrever um aviso com o nome de cada aluno e escolher quem recebe;
- programar o envio para a hora certa;
- conferir no histórico se o aviso chegou.
