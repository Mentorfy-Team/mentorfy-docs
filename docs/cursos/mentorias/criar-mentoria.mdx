A mentoria é o produto que o seu aluno compra. Crie a mentoria primeiro: depois você coloca os módulos e as aulas dentro dela.

<Aula slug="minhas-mentorias" />

## Passo a passo

<Passos>
  <Passo titulo={<>No menu, abra <strong>Minhas Mentorias</strong> e clique em <strong>Nova Mentoria</strong>.</>}>
    O botão fica no canto de cima, à direita.
  </Passo>
  <Passo titulo={<>Escolha <strong>Manual</strong>.</>}>
    **Manual** cria do zero, com total liberdade. **MentorAI** é a construção guiada por IA.

    ![Janela Nova Mentoria com as opções MentorAI e Manual](/img/guia/minhas-mentorias/02-modo.jpg)
  </Passo>
  <Passo titulo={<>Escolha <strong>Produto Único</strong>.</>}>
    Cria uma mentoria completa de uma vez. **Múltiplos Produtos** serve para criar várias de uma só vez.
  </Passo>
  <Passo titulo={<>Em <strong>Nome da Mentoria</strong>, dê um nome.</>}>
    É o nome que o aluno vê. Dá para trocar depois.
  </Passo>
  <Passo titulo={<>Em <strong>Tipo de Mentoria</strong>, escolha o formato.</>}>
    **Curso Online** é o formato com aulas em vídeo. Veja os outros tipos em Referência, logo abaixo.

    ![Formulário Nova Mentoria - Manual com os quatro tipos](/img/guia/minhas-mentorias/06-tipo.jpg)
  </Passo>
  <Passo titulo={<>Clique em <strong>Criar Mentoria</strong>.</>}>
    Pronto: a mentoria já abre no editor, para você montar os módulos.
  </Passo>
</Passos>

## Bom saber

:::tip Mentoria e produto são a mesma coisa
Em algumas telas você vai ver "produto" no lugar de "mentoria". É o mesmo item.
:::

:::info Tem pouco tempo?
Depois de criar, a IA pode rascunhar um módulo inteiro para você. Veja [Crie um módulo com IA](/docs/cursos/mentorias/modulo-com-ia).
:::

## Referência

| Tipo | Para que serve (texto da tela) |
| --- | --- |
| **Kanban** | Metodologia de gerenciamento baseada em cartões para otimizar o fluxo de trabalho |
| **A. B. / Reels** | Variação do Kanban que facilita a visualização do progresso geral |
| **Curso Online** | Vídeos para transmitir conhecimento de especialistas em um assunto |
| **Mentoria Continuada** | Relacionamento de longo prazo para desenvolver habilidades específicas |

## Dúvidas comuns

<details>
<summary>Onde encontro a mentoria depois de criada?</summary>

Em **Minhas Mentorias**, na lista de cartões. Clique em **Editar** para voltar ao editor. O menu do cartão também tem **Configurações de Mentoria**, **Ver certificados**, **Duplicar** e **Exportar conteúdo**.

</details>

<details>
<summary>O que acontece se eu apagar uma mentoria?</summary>

Pelo menu do cartão, **Deletar mentoria** apaga a mentoria e tira o acesso de todos os alunos dela. A própria tela avisa: não dá para recuperar. Se só quer tirar a mentoria de vista, oculte na vitrine (veja [Controle o que aparece](/docs/cursos/vitrine/controlar-o-que-aparece)).

</details>
